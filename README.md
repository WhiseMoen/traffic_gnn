# Traffic GNN – адаптивное управление светофорами с помощью графовых нейросетей

Графовая нейронная сеть (GNN), которая динамически назначает длительности зелёных фаз светофоров в зависимости от текущей загруженности дорог.  
Проект на PyTorch и PyTorch Geometric, подходит для учебных и исследовательских целей.

## Структура проекта
traffic_gnn/
├── config.py # константы и гиперпараметры
├── graph.py # построение графа перекрёстков и визуализация
├── model.py # класс графовой нейросети TrafficGNN
├── simulation.py # логика симуляции очередей (шаг traffic_step)
├── train.py # цикл обучения и сохранение модели
├── utils.py # вспомогательные функции (тестирование)
├── data_loader.py # загрузка реальных данных из CSV (при необходимости)
├── requirements.txt # список зависимостей
└── README.md # этот файл

## Требования

- Python 3.8 или новее
- PyTorch (рекомендуется CPU‑версия для простоты)
- PyTorch Geometric
- NetworkX, Matplotlib, Pandas

pip install -r requirements.txt

Запуск обучения
По умолчанию обучение идёт на случайных данных — это позволяет сразу проверить работоспособность.
python train.py
В процессе обучения в консоли будут отображаться значения функции потерь (суммарная очередь) каждые 10 эпох, а в конце откроется окно с графиком.

После завершения в папке появится файл traffic_gnn_model.pth — сохранённая модель.

Тестирование модели
python -c "
from train import train
model, edge_index = train()
from utils import test_model
test_model(model, edge_index)
"

Использование реальных данных
Чтобы обучать модель не на случайных числах, а на реальных измерениях трафика, подготовьте CSV‑файл со столбцами:
time_step, node, flow_NS, flow_EW.

Пример:
time_step,node,flow_NS,flow_EW
0,0,12.5,8.3
0,1,9.1,15.0
0,2,5.2,11.7
...
python train.py ./my_traffic_data.csv
Если файл не указан, автоматически генерируются случайные данные.
